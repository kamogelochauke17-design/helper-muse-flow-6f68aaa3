# IntelliFlow Assistant

Create a modern app named AI-Productivity-Assistant that can generate emails, summarise meeting notes and create a task planner. The app should have a dark and light mode. Dark Mode is navy blue, Light mode is a light baby blue color, Medium Blue → links/buttons, Charcoal → normal text. Email Generater should have a language preference, you must be able to pick a country and specify which countries english you want to use, Tone selection of up to 3 tones. Tone options of polite, warm, persuasive, professional, formal, friendly, informal, direct/concise, apologetic, assertive, casual. It needs to be able to suggest a subject so there needs to be a part where you can type what your email is about and it generates an email and a subject. These should be able to be edited. It should be able to correct grammar according to country. It must be able to translate emails received. Indicate if email has been received/red/ deleted and it must have the time and date of those actions. Detect if Email was forwaded and which Email it was forwaded to. Indicate level of classification (Public → Internal → Confidential → Restricted/Highly Confidential) . Option to not allow the email to be forwaded. Meeting Notes Summariser should create attendance, take attendance, Mark Absentees. Send Absentees email with the minutes, Make matters arising for next meeting. Summary of decisions made and actions taken. Choose tone of Summary ( same as email). translate notes received. send emails of reminder to members who are assigned with projects/ assignment with their assignment after the meeting, the members who are included in the assignment and the deadline. Create a to-do list/ check list. Task Planner should prioritize tasks according to deadlines. Top priority in Red midium Yellow, LOw green. Display deadlines. Send Email reminder close to the due date, Send email of reminder to all members who are included on the task if task completion is dependent of other members as well. App should be able to display library of emails, task, and notes previosly done by the app. The app should be able to browse and pull up articles, pictures, links or things on the internet in order for the user to be able to reference. User should also be able to click reference and be taken straight to the article. Search icon to search previose projects/ Reference. Drafts icon for projects that are left undone. If user leaves the app without finishing project it should be taken to drafts by default and send user notification of unfinished project. Bin icon for deleted icons that will be deleted after 30 days. send user notification that deleted item will emptied from bin in 30 days. option to receive notifications. Option for new  project. Able to reference previouse project. Able to reference documents on device or part of document
